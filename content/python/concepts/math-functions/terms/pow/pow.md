The `pow()` function in Python returns a number raised to a specified power.

## Syntax

```py
pow(base, exp, mod)
```

- `base`: The number to raise to a power.
- `exp`: The exponent.
- `mod`: An optional modulus value.

## Example

```py
result = pow(2, 3)
print(result)
```

Output:

```text
8
```
